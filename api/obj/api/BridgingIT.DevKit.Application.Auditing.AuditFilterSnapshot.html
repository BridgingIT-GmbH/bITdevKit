Remarks

Values accept immutable audit scalars, JSON, one-dimensional scalar or object arrays, standard string-keyed dictionaries, and filter criteria. Dictionaries in values become ordinal string/object dictionaries. Total text and scalar value data is limited to 64 KiB, collections to 1024 items, and the copied graph to 4096 nodes.

Exceptions

ArgumentException

The input has unsupported values, invalid structure, or exceeds a limit.
