Remarks

An explicit unrestricted scope represents a successful host decision. Missing scopes and failed resolution must fail before a provider read.

Constructors

AuditReadScope(FilterModel, string, bool)

Validates and snapshots server-owned constraints without consulting a provider.

public AuditReadScope(FilterModel constraints, string revision, bool unrestricted = false)

Parameters

constraints FilterModel

Required filter criteria for a restricted scope, or null or an empty model for an unrestricted scope.

revision string

A nonempty Unicode revision of at most 128 characters without control characters.

unrestricted bool

Whether the host explicitly permits reads without row constraints.

Examples

var scope = new AuditReadScope(new FilterModel { Filters = [new("ModuleName", FilterOperator.Equal, "Sales")] }, "sales-v2");
