Examples

CacheBinaryLoadDelegate loader = async (context, destination, token) =>
{
    var source = (IReportSource)context.Services.GetService(typeof(IReportSource));
    await source.CopyToAsync(context.Item.Key, destination, token);
    return new CacheBinaryLoadResult();
};

Remarks

Write the complete logical payload to the supplied bounded destination using the owned token. Never retain, close, or dispose that destination. Use cache-owned scoped services and repeatable source reads because the engine may retry the loader. A joining caller's delegate may never run. Zero bytes are a positive empty payload. Return NotFound(CacheEntryDescriptor) only for confirmed source absence. Binary payload handles are opened independently only after storage publication is confirmed.
