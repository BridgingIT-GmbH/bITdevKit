Dimensions(Action<CacheDimensionsBuilder>)

Groups typed scalar, set, and interval dependency schema declarations for this collection.

public CacheCollectionBuilder Dimensions(Action<CacheDimensionsBuilder> configure)

Parameters

configure Action<CacheDimensionsBuilder>

Optional declarations to append in order. Null or an empty callback preserves existing declarations.

Returns

CacheCollectionBuilder

The same collection builder.

Examples

collection.Dimensions(d => d
    .Set<string>("tags")
    .Scalar<string>("region")
    .Interval<DateTimeOffset>("coverage"));

Remarks

Repeated callbacks append to this collection's declarations, including declarations added through individual helpers. Duplicate names are rejected using invariant normalization. Configuration can replace the complete schema list. The finalized catalog validates the sixteen-dimension bound and the supported interval kinds.

Exceptions

ArgumentException

A declaration has an invalid name, an unsupported scalar type, or a duplicate normalized name.
