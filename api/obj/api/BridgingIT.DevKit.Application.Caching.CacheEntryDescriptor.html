A new descriptor preserving existing dimensions and entry overrides.

Type Parameters

T

A signed integer alias or DateTimeOffset, including their nullable forms with non-null endpoints.

Examples

Remarks

Endpoints use the existing canonical comparison and snapshot rules. The descriptor permits at most sixteen dimensions.

Exceptions

The type, name, endpoints, or dimension count is invalid.

WithSetDimension<T>(string, params T[])

Returns a descriptor with an additional typed set dependency and a defensive member snapshot.

public CacheEntryDescriptor WithSetDimension<T>(string name, params T[] values)

Parameters

name string

The declared set dimension name.

values T[]

At most 256 members. An empty array retains the kind declared by T.

Returns

CacheEntryDescriptor

A new descriptor preserving existing dimensions and entry overrides.

Type Parameters

T

A supported portable scalar type, including nullable signed integer, Boolean, Guid, or DateTimeOffset types.

Examples

var descriptor = new CacheEntryDescriptor().WithSetDimension("regions", "west", "east");

Remarks

Supports String, Boolean, signed integer aliases, Guid, and DateTimeOffset. Duplicate members normalize through the existing dimension factory. Null members retain the declared kind and require the collection schema's null permission at admission. The descriptor permits at most sixteen dimensions.

Exceptions

ArgumentNullException

values is null.

ArgumentException

The type, name, members, or dimension count is invalid.
