Checks persisted header compatibility and each stored frame before exposing its payload bytes.

public sealed class CacheEnvelopeReader : Stream
Inheritance
object
MarshalByRefObject
Stream
CacheEnvelopeReader

Examples

var opened = await CacheEnvelopeReader.OpenAsync(source, metadata, transient, resident, cancellationToken);

Remarks

Sequential EOF verifies the footer and full stored representation. Seeking or positioned ranges establish only affected-frame integrity. Disposal releases reader buffers and leaves source ownership with its provider handle.
