WithSetDimension<T>(string, params T[])

Returns an item with an additional typed set dependency and a defensive member snapshot.

public CacheItem WithSetDimension<T>(string name, params T[] values)

Parameters

name string

The declared set dimension name.

values T[]

At most 256 members. An empty array retains the kind declared by T.

Returns

CacheItem

A new item preserving its key and existing dimensions.

Type Parameters

T

A supported portable scalar type, including nullable signed integer, Boolean, Guid, or DateTimeOffset types.

Examples

var item = new CacheItem("report:42").WithSetDimension("regions", "west", "east");

Remarks

Supports String, Boolean, signed integer aliases, Guid, and DateTimeOffset. Duplicate members normalize through the existing dimension factory. Null members retain the declared kind and require the collection schema's null permission at admission. The item permits at most sixteen dimensions.

Exceptions

ArgumentNullException

values is null.

ArgumentException

The type, name, members, or dimension count is invalid.
