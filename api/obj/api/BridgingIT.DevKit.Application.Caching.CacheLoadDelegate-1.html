Examples

CacheLoadDelegate<ProductCard> loader = async (context, token) =>
{
    var source = (IProductSource)context.Services.GetService(typeof(IProductSource));
    var card = await source.FindAsync(context.Item.Key, token);
    return card is null
        ? CacheLoadResult<ProductCard>.NotFound()
        : new CacheLoadResult<ProductCard>(card);
};

Remarks

Resolve scoped dependencies through Services instead of capturing a request scope that can end while shared work continues. A delegate may run more than once under the configured retry policy, or may never run when its caller joins another owner. Return explicit absence only after a successful source read confirms it. Do not start nested cache source loads, refreshes, or bypass work from a loader.
