Remarks

Successful unretained typed completion rechecks storage and reacquires shared authority within the existing node flight and original deadline. A defensive cap of 32 remote handoffs rejects repeated nonretention with CoordinationTimeout; it never transfers a remote graph or resets caller/source budgets.
