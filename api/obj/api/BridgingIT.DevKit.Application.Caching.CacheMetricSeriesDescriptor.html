Identifies one configured diagnostic series with explicit unit, scope and aggregation semantics.

public CacheMetricSeriesDescriptor(string Id, string Collection, string Metric, string Unit, string Aggregation, string Scope, CacheObservationAccuracy Accuracy = CacheObservationAccuracy.Exact)

Parameters

Id string

The bounded declared series identifier.

Collection string

The declared collection alias, or null for node aggregates.

Metric string

The controlled event, gauge or sampled-quantile family.

Unit string

Events/s, entries/s, work, bytes, percent, or seconds.

Aggregation string

DurationWeightedRate for counters, Last for gauges and sampled quantiles.

Scope string

NodeLocal; provider storage counts are never summed into these execution series.

Accuracy CacheObservationAccuracy

Exact observations, sampled histograms/process measurements, or an unavailable source.
