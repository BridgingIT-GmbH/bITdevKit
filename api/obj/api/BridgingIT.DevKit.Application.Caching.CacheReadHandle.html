WaitForCompletionAsync(CancellationToken)

Observes completion without reading, draining, rewinding, or owning the destination.

public ValueTask<Result<CacheReadCompletion>> WaitForCompletionAsync(CancellationToken cancellationToken = default)

Parameters

cancellationToken CancellationToken

Cancels only this observation wait.

Returns

ValueTask<Result<CacheReadCompletion>>

Validated full consumption, completed range consumption, incomplete consumption, or a classified terminal failure.

Examples

await handle.Stream.CopyToAsync(destination, cancellationToken);
var completion = await handle.WaitForCompletionAsync(cancellationToken);
if (completion.IsSuccess && completion.Value == CacheReadCompletion.Validated) { ConfirmPayloadIntegrity(); }

Remarks

Consume or dispose the stream before waiting for a terminal outcome, or observe it concurrently with consumption. Cancelling this observation does not cancel consumption or dispose the handle. Successful validation makes no claim about a destination or transport.
