Examples

await using var handle = acquired.Value; await handle.Stream.CopyToAsync(destination); var terminal = await handle.WaitForCompletionAsync();

Remarks

Only one positioned read or validation operation may run at a time. A canceled asynchronous read stops the caller wait while an ignored native read retains the owned buffer and reservations until it ends.
