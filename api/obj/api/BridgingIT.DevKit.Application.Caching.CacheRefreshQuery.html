Namespace string

The host's current contract version; other deployments' contracts are excluded.

Now DateTimeOffset

The fixed sweep time used for validity and activity eligibility.

RefreshAhead TimeSpan

The maximum lead, additionally capped to twenty percent of published lifetime.

ActivityWindow TimeSpan

The finite foreground-activity window.

Limit int

The maximum indexed candidates examined, at most 1,000.

Continuation string

The provider-issued bounded index continuation, or null for a new pass.
