Remarks

Configure this builder during startup from one thread. Resolved codec and validator instances are reused by their collection and must support concurrent calls without retaining per-call state or request-scoped dependencies. Each profile must declare a unique persisted format identifier and version within this contract.

Remarks

The estimator can be reused concurrently and must not capture request-scoped dependencies. Include referenced objects in the estimate. Unknown, negative, or oversized estimates decline decoded retention. This method preserves any earlier immutable-sharing approval but does not grant it on its own.

WithJsonOptions(JsonSerializerOptions)

Replaces the JSON profile with the standard JSON codec using a registration-time options snapshot.

public CacheValueContractBuilder<T> WithJsonOptions(JsonSerializerOptions options)

Parameters

options JsonSerializerOptions

Caller-owned JSON conventions copied immediately without freezing the caller's instance.

Returns

CacheValueContractBuilder<T>

This builder for further contract configuration.

Examples

contract.WithJsonOptions(JsonSerializerOptions.Web);

Remarks

Later changes to the options or its converter list do not change this registration. Converter and resolver objects are shared references and must remain safe for concurrent use. This replaces any earlier JSON codec and validator; use WithJsonCodec(Func<IServiceProvider, IValueCodec<T>>, Func<IServiceProvider, IValueCodecValidator<T>>) when an encoded-write validator is required. The persisted format remains JSON version 1, so choose conventions compatible with retained entries or change the collection's contract version. Other codec profiles and decoded-sharing settings remain unchanged.

Exceptions

ArgumentNullException

options is null.
