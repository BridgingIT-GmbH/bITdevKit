Reads and loads derived values through one declared, bounded typed collection.

public interface ICacheCollection<T>

Type Parameters

T

The collection's one declared value contract.

Examples

var result = await collection.GetOrLoadAsync(new("product:42"), loader, cancellationToken);

Remarks

Values are read-only and may be shared between callers without cloning. Copy a value before changing it. A successful lookup distinguishes a value, including a permitted null or empty value, from confirmed source absence and a cache miss. Source success and storage success are separate. Check StorageOutcome before assuming a loaded value was retained.
