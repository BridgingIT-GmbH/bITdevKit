Defines a code-approved, versioned, streaming persisted transformation. Factories must honor forward-only access and finite state charges.

public interface ICachePayloadTransform : IStreamingPayloadTransform

Examples

caching.WithPayloadTransform("authenticated", services => new AuthenticatedTransform(services));

Remarks

Encoding streams write to the supplied destination; decoding streams read from the supplied source. Disposing a wrapper may close that supplied view. Implementations are shared between calls and must be thread safe; each returned stream owns only its per-transfer state. No whole-value buffering is permitted. The inherited streaming contract forwards to these cache members, including explicit interface implementations.
