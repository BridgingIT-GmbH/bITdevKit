Owns an independently positioned, lifetime-bounded snapshot stream and its provider reservations.

public interface ICacheReadHandle

Examples

await using var handle = result.Value.Value; await handle.Stream.CopyToAsync(destination, cancellationToken);

Remarks

Dispose the handle asynchronously to release the snapshot and its resource reservations. Consume one handle sequentially, without concurrent reads or seeks. An acquired snapshot remains independent of later replacement or invalidation, but its configured transfer deadlines still apply. Payload integrity, destination writes, and transport delivery are separate outcomes. Successful acquisition alone does not establish payload integrity.

Remarks
