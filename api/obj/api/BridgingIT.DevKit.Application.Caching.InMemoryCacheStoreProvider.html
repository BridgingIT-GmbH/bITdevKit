Owns authoritative in-process payloads, metadata indexes, publication fences, reader pins, and finite quota.

public sealed class InMemoryCacheStoreProvider : ICacheStoreProvider

Examples

var provider = new InMemoryCacheStoreProvider("memory");

Remarks

Restart empties the store. Shared-store source coordination and durable reconciliation require a capable persistent provider.
