public static ApplicationCachingBuilderContext AddApplicationCaching(this IServiceCollection services, IConfiguration configuration = null)

Parameters

services IServiceCollection

The host service collection shared by the contributing modules.

configuration IConfiguration

An optional host root, read at Caching:Application, or explicit section read directly.

Returns

ApplicationCachingBuilderContext

The shared startup builder for this service collection.

Examples

services.AddApplicationCaching(catalogSection).WithValueContract<ProductCard>("catalog-card");
services.AddApplicationCaching(ordersSection).WithValueContract<OrderSummary>("orders-summary");

Remarks

Root and section selection is identical with or without a setup callback. Complete all module registrations before resolving cache services or calling BuildCatalog. Runtime services and workers are registered once.
