Provides a listener that ensures mutual exclusion for job execution within specified groups.

public class ConcurrentGroupExecutionListener : IJobListener
Inheritance
object
ConcurrentGroupExecutionListener
Implements
IJobListener

Remarks

This listener uses semaphores to enforce that only one job within a specified group can execute at a time. It is configured with a set of groups for which mutual exclusion is required. Jobs in other groups are not affected.
