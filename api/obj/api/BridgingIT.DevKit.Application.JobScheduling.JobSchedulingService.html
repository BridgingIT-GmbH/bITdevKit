Background service responsible for configuring and starting Quartz.NET job scheduling once the application host has fully started.

public class JobSchedulingService : BackgroundService

object
BackgroundService
JobSchedulingService

Remarks

This service intentionally uses Microsoft.Extensions.Hosting.IHostApplicationLifetime.ApplicationStarted to delay scheduling until the host is ready. As the callback is synchronous, all asynchronous work is explicitly managed and tied to the host shutdown lifecycle.
