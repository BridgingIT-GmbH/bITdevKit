Remarks

The broker is initialized only after the application host has fully started. As startup is triggered via Microsoft.Extensions.Hosting.IHostApplicationLifetime.ApplicationStarted, asynchronous work is explicitly tracked and coordinated with host shutdown to avoid running after dependency injection container disposal.
