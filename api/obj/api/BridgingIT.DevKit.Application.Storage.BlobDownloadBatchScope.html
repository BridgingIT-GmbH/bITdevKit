Class BlobDownloadBatchScope

Namespace
BridgingIT.DevKit.Application.Storage

BridgingIT.DevKit.Application.Storage.dll

Carries the key set of a bulk download to the innermost provider call, so a provider that implements IBlobStoreBatchDownloadProvider can read the keys in batches while each key still travels through the complete client behavior pipeline on its own.
