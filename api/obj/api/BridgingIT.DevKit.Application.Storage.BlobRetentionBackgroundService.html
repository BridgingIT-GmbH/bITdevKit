Examples

var service = serviceProvider.GetRequiredService<BlobRetentionBackgroundService>();

Remarks

The service is safe to register even when no configured provider supports retention sweeping. Each provider is responsible for using native indexes, leases, or conditional deletes so multiple application nodes can sweep safely.
