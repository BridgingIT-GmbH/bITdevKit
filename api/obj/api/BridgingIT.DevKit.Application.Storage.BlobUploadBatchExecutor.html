Remarks

Uploads commit independently. The coordinator never buffers, disposes, or retries caller-owned streams.

Returns

A completed outcome collection, or a validation failure for invalid batch arguments.

Examples

var batch = await BlobUploadBatchExecutor.ExecuteAsync(blobs, uploads, new() { MaxConcurrency = 2 }, cancellationToken);

Remarks

Duplicate keys and shared streams produce item-level validation failures. Unexpected per-item exceptions produce indeterminate outcomes because a provider or decorator may already have committed. The outer Result succeeds when coordination completes, even if individual uploads fail.

Exceptions

OperationCanceledException

Caller cancellation interrupts the batch; no complete outcome collection is returned.
