Remarks

DocumentStoreClient<T> uses this contract for UpsertManyAsync and DeleteManyAsync when the provider implements it and otherwise applies the operations one by one.

Implementations must keep the semantics of the per-operation path: operations apply in input order, an operation sees the effect of the earlier operations of the same call (including duplicate keys), the call stops at the first failing operation, and the operations before it stay committed. The failing key is reported in FailedKey and the failure messages are carried on the returned result.
