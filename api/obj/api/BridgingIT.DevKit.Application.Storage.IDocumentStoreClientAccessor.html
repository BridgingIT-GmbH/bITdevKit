Remarks

The dashboard uses this adapter after selecting a DocumentStoreClientDescriptor. Implementations delegate to the same container-owned typed client used by application code, preserving behaviors, validation, concurrency, expiration, and provider lifetime. It is not a second persistence API for normal application use.
