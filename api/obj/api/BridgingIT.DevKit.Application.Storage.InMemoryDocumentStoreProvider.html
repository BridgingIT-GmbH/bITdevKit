Examples

var provider = new InMemoryDocumentStoreProvider(loggerFactory);

Remarks

State is local to the provider instance and is not shared across application processes. All synchronization and backing collections remain private; returned bytes, records, and property bags are cloned so caller mutation cannot alter stored state. The provider is useful for tests and single-process scenarios, not distributed persistence.
