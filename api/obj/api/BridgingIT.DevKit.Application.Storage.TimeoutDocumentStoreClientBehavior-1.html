DeleteManyAsync(IReadOnlyCollection<DocumentDelete>, CancellationToken)

Deletes an ordered collection of physical documents and reports explicit partial completion.

public override Task<Result<DocumentBatchResult<DocumentKey>>> DeleteManyAsync(IReadOnlyCollection<DocumentDelete> deletes, CancellationToken cancellationToken = default)

Parameters

deletes IReadOnlyCollection<DocumentDelete>

The exact keys and optional per-item ETag conditions to validate completely and process in input order.

cancellationToken CancellationToken

The token used to cancel the operation.

Returns

Task<Result<DocumentBatchResult<DocumentKey>>>

A result containing successfully processed keys in input order and the first failed key when processing stops. The complete collection is not guaranteed to be atomic across provider transaction boundaries.

Examples

var deletes = entries
    .Select(entry => new DocumentDelete(
        entry.Key,
        new DocumentDeleteOptions { IfMatchETag = entry.ETag }))
    .ToArray();
var result = await documents.DeleteManyAsync(deletes, cancellationToken);

Remarks

All input is materialized and validated before the first provider delete. Deleting an already absent item is idempotent, while an ETag mismatch is reported as a conflict and can leave earlier deletes committed.

public override Task<Result<DocumentBatchResult<DocumentInfo>>> UpsertManyAsync(IReadOnlyCollection<DocumentWrite<T>> writes, CancellationToken cancellationToken = default)

Parameters

writes IReadOnlyCollection<DocumentWrite<T>>

The writes to validate completely and process in input order. Each item can carry independent concurrency, integrity, property, and expiration options.

cancellationToken CancellationToken

The token used to cancel the operation.

Returns

Task<Result<DocumentBatchResult<DocumentInfo>>>

A result containing metadata for successful writes in input order and the first failed key when processing stops. The complete collection is not guaranteed to be atomic across provider transaction boundaries.

Examples

var writes = customers
    .Select(customer => new DocumentWrite<Customer>(
        new DocumentKey("customers", customer.Id),
        customer))
    .ToArray();
var result = await documents.UpsertManyAsync(writes, cancellationToken);

Remarks

All input is materialized and validated before the first provider write. Once processing begins, a provider failure can leave earlier items committed; callers must inspect the returned DocumentBatchResult<T>.
