RunAsync(CliWorkspaceContext, IReadOnlyList<string>, bool, Action<string>, CancellationToken, CancellationToken)

Builds and starts DevKit web hosts of the current checkout and streams their output until they exit.

public Task<DevAppInstanceCliOutcome> RunAsync(CliWorkspaceContext workspace, IReadOnlyList<string> appIds, bool noBuild, Action<string> output, CancellationToken stopToken, CancellationToken killToken = default)

Parameters

workspace CliWorkspaceContext

The CLI workspace.

appIds IReadOnlyList<string>

The application IDs to start, or an empty list for all hosts.

noBuild bool

A value indicating whether the build step is skipped.

output Action<string>

Receives progress lines and the prefixed host output lines.

stopToken CancellationToken

Signals that the hosts should stop, usually Ctrl+C.

killToken CancellationToken

Signals that the hosts must be terminated immediately.

Returns

Task<DevAppInstanceCliOutcome>

The outcome after all hosts exited.

Remarks

The hosts build one after another, because parallel builds of shared projects collide on obj files. They then run concurrently with dotnet run --no-build and their launch profile. In a linked worktree each host isolates itself, so the launch profile ports are replaced by the slot ports. Hosts whose instance is already running are skipped. When stopToken fires, the service asks managed instances to stop through their stop file, waits RunShutdownTimeout, then terminates the remaining process trees.
