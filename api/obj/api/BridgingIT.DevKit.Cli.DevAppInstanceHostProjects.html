Remarks

Projects recorded in the registry inventory come first, because their application ID is the one the host used, including IDs set with WithAppId. The scan then adds every Microsoft.NET.Sdk.Web project whose top-level C# files call DevKitWebApplication.CreateBuilder, with the ID derived from its assembly name.
