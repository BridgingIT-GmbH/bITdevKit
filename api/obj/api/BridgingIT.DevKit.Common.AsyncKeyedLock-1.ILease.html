Examples

var acquired = await lease.TryAcquireAsync(TimeSpan.Zero);

Remarks

Dispose can be called repeatedly. During a pending wait, disposal defers cleanup until the wait settles. Use the acquisition's cancellation token to interrupt the wait. Keep the lease alive while using an acquired lock.

Methods

TryAcquireAsync(TimeSpan, CancellationToken)

Attempts to acquire the reserved key once.

Task<bool> TryAcquireAsync(TimeSpan timeout, CancellationToken cancellationToken = default)

Parameters

timeout TimeSpan

The wait limit. Use zero for an immediate attempt or System.Threading.Timeout.InfiniteTimeSpan to wait indefinitely.

cancellationToken CancellationToken

The token used to cancel the wait.

Returns

Task<bool>

True on acquisition or false on timeout. A timeout, cancellation, or failed wait returns the reservation to the pool.

Examples

var acquired = await lease.TryAcquireAsync(TimeSpan.FromSeconds(2), cancellationToken);

Exceptions

OperationCanceledException

cancellationToken is canceled during the attempt.

ArgumentOutOfRangeException

timeout is outside the range accepted by System.Threading.SemaphoreSlim.WaitAsync(System.TimeSpan, System.Threading.CancellationToken).

InvalidOperationException

An attempt is already pending or the lease already owns the lock.

ObjectDisposedException

The lease was already disposed, or disposal was requested during a wait that acquired the lock.
