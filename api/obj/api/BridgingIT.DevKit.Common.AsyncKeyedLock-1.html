Examples

using var locks = new AsyncKeyedLock<string>(StringComparer.OrdinalIgnoreCase);
using var lease = locks.Rent("report-42");
if (await lease.TryAcquireAsync(TimeSpan.FromSeconds(2)))
{
    await RefreshReportAsync("report-42");
}

Remarks

Each instance coordinates work in the current process. Equal keys share a semaphore even if rented by the same caller. Different keys can be acquired independently. Dispose each lease to retire unused keys.

Parameters

key TKey

The key to lock.

timeout TimeSpan

The wait limit. Use zero for an immediate attempt or System.Threading.Timeout.InfiniteTimeSpan for an indefinite wait.

cancellationToken CancellationToken

The token used to cancel the wait.

Returns

Task<AsyncKeyedLock<TKey>.ILease>

The acquired lease on success, or null on timeout. The caller disposes a returned lease to release the lock.

Examples

Exceptions

ArgumentOutOfRangeException
