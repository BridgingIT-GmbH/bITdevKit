Examples

var history = new BoundedTimeSeries<Measurement>(120, point => point.At);
history.Add(new Measurement(DateTimeOffset.UtcNow, 42));
var window = history.Query(DateTimeOffset.UtcNow.AddMinutes(-1), DateTimeOffset.UtcNow, 30);

Remarks

The oldest appended observation is overwritten when capacity is reached. This type is not thread-safe; callers synchronize reads and writes and keep retained observations immutable. Timestamps need not be appended in order.

Examples

var points = history.Query(start, end, 30, bucket => bucket[^1]);

Remarks

Downsampling partitions the selected observations into equally sized buckets by index. No observations or timestamps are interpolated. A supplied aggregator owns value, timestamp and missing-data semantics.

Exceptions

ArgumentOutOfRangeException

The point limit is not positive.

ArgumentException

The end precedes the start.
