AddIfAll<T>(ICollection<T>, T, params Func<T, bool>[])

Adds an item to the collection if all specified conditions are true. If the collection is null, returns silently without adding.

public static ICollection<T> AddIfAll<T>(this ICollection<T> collection, T item, params Func<T, bool>[] predicates)

Parameters

collection ICollection<T>

The collection to add to, or null.

item T

The item to add.

predicates Func<T, bool>[]

The predicates that must all return true. Add if empty

Returns

ICollection<T>

The collection (for chaining if desired), or null if the collection was null.

Type Parameters

T

The type of items in the collection.

Examples

var orderItems = new List<Item>();
var item = new Item { Price = 25.0m, Quantity = 1 };
orderItems.AddIfAllConditions(item, x => x.Price > 20.0m, x => x.Quantity > 0); // Adds if both true
orderItems = null;
orderItems.AddIfAllConditions(item, x => x.Price > 20.0m); // Does nothing and returns null silently

Exceptions

ArgumentNullException

Thrown if predicates is null or empty and the collection is not null.

AddIfUnique<T>(ICollection<T>, T, IEqualityComparer<T>)

Adds an item to the collection if it doesn’t already exist, based on equality or a custom comparer. If the collection is null, returns silently without adding.

public static ICollection<T> AddIfUnique<T>(this ICollection<T> collection, T item, IEqualityComparer<T> comparer = null)

Parameters

collection ICollection<T>

The collection to add to, or null.

item T

The item to add.

comparer IEqualityComparer<T>

The comparer to determine uniqueness, or null to use the default equality comparer.

Returns

ICollection<T>

The collection (for chaining if desired), or null if the collection was null.

Type Parameters

T

The type of items in the collection.

Examples

var orderItems = new List<Item> { new Item { Id = 1 } };
var newItem = new Item { Id = 1 };
orderItems.AddIfUnique(newItem, Comparer<Item>.Create((a, b) => a.Id.CompareTo(b.Id))); // Won’t add if Id matches
orderItems = null;
orderItems.AddIfUnique(newItem); // Does nothing and returns null silently

AddRangeIf<T>(ICollection<T>, IEnumerable<T>, bool)

public static ICollection<T> AddRangeIf<T>(this ICollection<T> collection, IEnumerable<T> items, bool condition)

Parameters

collection ICollection<T>

The collection to add to, or null.

items IEnumerable<T>

The items to add.

condition bool

The condition that must be true to add the items.

Returns

ICollection<T>

The collection (for chaining if desired), or null if the collection was null.

Type Parameters

T

The type of items in the collection.

Examples

var orderItems = new List<Item>();

orderItems = null;
