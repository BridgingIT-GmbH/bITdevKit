Provides ambient access to the application correlation identifier for the current execution flow.

public static class CorrelationId
Inheritance
object
CorrelationId

Examples

using (CorrelationId.BeginScope("order-123"))
{
    logger.LogInformation("Processing correlation {CorrelationId}", CorrelationId.Current);
}

Remarks

The correlation identifier is independent from the distributed tracing System.Diagnostics.ActivityTraceId. An explicitly established scope takes precedence over the correlation value stored in the current activity baggage.
