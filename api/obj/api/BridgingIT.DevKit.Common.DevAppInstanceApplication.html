Methods

DeriveAppId(string)

Derives an application ID from a host application name. Trailing layer segments such as Presentation, Web, Server, Api or Host are dropped, the last remaining segment is lowercased, and characters outside a-z0-9 become hyphens. A result longer than MaxAppIdLength is cut and ends with an 8-character hash of the full name.

public static string DeriveAppId(string applicationName)

Parameters
