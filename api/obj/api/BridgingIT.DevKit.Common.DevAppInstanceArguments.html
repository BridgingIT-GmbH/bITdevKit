Reserved command-line arguments that start a host in a one-shot development instance mode.

public static class DevAppInstanceArguments
Inheritance
object
DevAppInstanceArguments

Examples

var args = new[] { DevAppInstanceArguments.FormatReset("forecasthub", 2) };
// args[0] == "--bdk-dev-reset=forecasthub:w02"

Remarks

bdk dev reset and bdk dev prune --confirm start the application project with these arguments. The host runs the declared adapters instead of starting the listener, then exits with DevAppInstanceArguments.ExitCodes.
