Remarks

The builder is pure data. Registration evaluates eligibility first, so an inactive host never runs adapter code.

WithDatabases(IDevAppInstanceDatabaseAdapter)

Registers a database adapter that finds its connection strings in configuration and gives each linked worktree its own database <database>_wNN. Adapters of the DevKit EF Core provider packages, and adapters declared with DevAppInstanceDatabaseAdapterAttribute, are found automatically. Declare an adapter here when it is not found automatically, or to run it before the automatically found adapters.

public DevAppInstanceBuilder WithDatabases(IDevAppInstanceDatabaseAdapter adapter)

WithHttpOffset(int, int?)

Declares the HTTP and HTTPS port offsets within a slot block. Optional. Without them, the registry assigns the lowest free offset pair of the repository on the first start and reuses it afterwards, so a single host gets 0 and 1. Declare offsets when several hosts share a repository and each needs the same ports in every clone.

public DevAppInstanceBuilder WithHttpOffset(int http, int? https = null)

Parameters

http int

The HTTP port offset.

https int?

The HTTPS port offset, or null for http + 1.

Returns

DevAppInstanceBuilder

The builder.

Examples
