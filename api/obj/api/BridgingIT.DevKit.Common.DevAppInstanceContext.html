Examples

var context = app.Services.GetRequiredService<DevAppInstanceContext>();
if (context.IsActive)
{
    Console.WriteLine($"{context.AppId} slot {context.Slot}: {context.HttpsUrl}");
}

Remarks

An inactive context has IsActive set to false, reports InactiveReason and never carries a worktree ID, slot, URL or path. Use ToStatus() for the sanitized projection. The full context contains local paths and managed values and is never sent to a browser.
