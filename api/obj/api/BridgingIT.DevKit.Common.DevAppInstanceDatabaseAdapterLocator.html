Finds the database adapters of the provider assemblies that ship with the application. Each provider assembly declares its adapter with DevAppInstanceDatabaseAdapterAttribute.

public static class DevAppInstanceDatabaseAdapterLocator
Inheritance
object
DevAppInstanceDatabaseAdapterLocator

Examples

var adapters = DevAppInstanceDatabaseAdapterLocator.Locate();

Remarks

The locator loads the DevKit Entity Framework provider assemblies by name when they are present, because modules usually register their DbContext after AddDevAppInstance runs and the runtime loads assemblies on first use. It also reads assemblies that are already loaded, which covers third-party adapters. The SQL Server adapter comes first, then PostgreSQL, then SQLite, then any other adapter.
