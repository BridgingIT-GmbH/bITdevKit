GetStartupRecoveryAction()

Gets the recovery action for a host startup error, followed by how to start without worktree isolation. Use it with a structured log template that passes the log key as an argument.

public string GetStartupRecoveryAction()

Returns

string

The recovery action including the opt-out hint, or only the hint when no recovery action is known.

Examples

logger.LogError(
    "[{LogKey}] worktree failure: {ErrorMessage} (code={ErrorCode}, app={AppId}, slot={Slot}) {RecoveryAction}",
    "BDK", exception.Message, exception.Code, exception.AppId, exception.Slot, exception.GetStartupRecoveryAction());
