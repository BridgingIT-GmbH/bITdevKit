Resolves the immutable DevAppInstanceContext of a host.

public static class DevAppInstanceResolver
Inheritance
object
DevAppInstanceResolver

Examples

var context = DevAppInstanceResolver.Resolve(request);
if (context.IsActive) { builder.Configuration.AddInMemoryCollection(context.ManagedValues); }

Remarks

Eligibility is evaluated first. Ineligible and ordinary-checkout hosts get an inactive context without any file access beyond Git detection. Linked worktrees create or recover their persistent assignment under the registry lock.
