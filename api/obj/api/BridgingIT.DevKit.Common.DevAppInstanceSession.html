Remarks

AddDevAppInstance registers the session as a singleton instance. A registration calls ResolveConnectionString(IServiceCollection, IDevAppInstanceDatabaseAdapter, string, string) with its adapter and connection string. When the adapter kind is new, the session discovers and plans its databases, records them in the inventories and applies the managed values to configuration. Without a session, or when the instance is inactive, connection strings stay unchanged.

FallBack(DevAppInstanceException)

Switches the session to the configured defaults after isolation failed. The context becomes inactive with the reason Fallback, the managed values and the lease are released and the failure is written to the startup output. Later connection strings stay unchanged.

ResolveConnectionString(IServiceCollection, IDevAppInstanceDatabaseAdapter, string, string)

Returns the connection string a provider registration must use. Finds the session in services, adds the adapter when its kind is new and maps an ordinary database to the instance database.
