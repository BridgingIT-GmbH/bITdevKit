AddIfAll<TKey, TValue>(IDictionary<TKey, TValue>, TKey, TValue, params Func<TValue, bool>[])

Adds a key-value pair to the dictionary if all specified conditions are true for the value. If the dictionary is null, returns silently without adding.

public static IDictionary<TKey, TValue> AddIfAll<TKey, TValue>(this IDictionary<TKey, TValue> dictionary, TKey key, TValue value, params Func<TValue, bool>[] predicates)

Parameters

dictionary IDictionary<TKey, TValue>

The dictionary to add to, or null.

key TKey

The key of the item to add.

value TValue

The value of the item to add.

predicates Func<TValue, bool>[]

The predicates that must all return true. Adds if empty.

Returns

IDictionary<TKey, TValue>

The dictionary (for chaining if desired), or null if the dictionary was null.

Type Parameters

TKey

The type of the keys in the dictionary.

TValue

The type of the values in the dictionary.

Examples

var dict = new Dictionary<int, string>();
dict.AddIfAll(1, "one", v => v.Length > 2, v => v.StartsWith("o")); // Adds if both true
dict = null;
dict.AddIfAll(2, "two", v => v.Length > 2); // Does nothing and returns null silently

AddRangeIf<TKey, TValue>(IDictionary<TKey, TValue>, IEnumerable<KeyValuePair<TKey, TValue>>, bool)

Adds a range of key-value pairs to the dictionary if the specified condition is true. If the dictionary is null, returns silently without adding.

public static IDictionary<TKey, TValue> AddRangeIf<TKey, TValue>(this IDictionary<TKey, TValue> dictionary, IEnumerable<KeyValuePair<TKey, TValue>> items, bool condition)

Parameters

dictionary IDictionary<TKey, TValue>

The dictionary to add to, or null.

items IEnumerable<KeyValuePair<TKey, TValue>>

The key-value pairs to add.

condition bool

The condition that must be true to add the items.

Returns

IDictionary<TKey, TValue>

The dictionary (for chaining if desired), or null if the dictionary was null.

Type Parameters

TKey

The type of the keys in the dictionary.

TValue

The type of the values in the dictionary.

Examples

var dict = new Dictionary<int, string>();
var items = new Dictionary<int, string> { { 1, "one" }, { 2, "two" } };
dict.AddRangeIf(items, items.Any(kvp => kvp.Value.Length > 2)); // Adds all if any value length > 2
dict = null;
dict.AddRangeIf(items, true); // Does nothing and returns null silently

Exceptions

ArgumentNullException

Thrown if items is null and the dictionary is not null.
