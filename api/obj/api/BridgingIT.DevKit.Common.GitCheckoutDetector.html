Detects ordinary checkouts and linked worktrees from Git's documented on-disk layout.

Examples

var checkout = GitCheckoutDetector.Detect(builder.Environment.ContentRootPath, new ProcessGitCommandRunner());

Remarks

Detection ignores GIT_DIR, GIT_WORK_TREE and GIT_COMMON_DIR. A Git process is started only when the files are inconclusive and a runner is supplied. Design-time callers pass no runner. Detection needs neither a Git installation nor a repository: a directory without .git is OutsideGit. Unusable metadata without linked-worktree evidence is also reported as outside Git, with Warning set. Only unconfirmable linked-worktree metadata fails with worktree_detection_failed.
