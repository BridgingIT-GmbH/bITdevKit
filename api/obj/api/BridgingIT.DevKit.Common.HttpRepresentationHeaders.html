SelectRange(HttpRequest, long, string, DateTimeOffset)

Selects one contiguous byte range, or the full representation when Range is absent or If-Range does not match.

public static HttpRepresentationRangeSelection SelectRange(HttpRequest request, long length, string entityTag, DateTimeOffset lastModified)

Parameters

request HttpRequest

The request containing Range and optional If-Range headers.

length long

The nonnegative length of the selected representation in bytes.

entityTag string

Its current strong, quoted entity tag.

lastModified DateTimeOffset

Its last modification timestamp, compared at whole-second precision.

Returns

HttpRepresentationRangeSelection

A full or partial selection, or an unsupported or unsatisfiable range classification.

Examples

var range = HttpRepresentationHeaders.SelectRange(request, contentLength, entityTag, modifiedAt);
            if (range.Outcome == HttpRepresentationRangeKind.Partial) { await CopyRangeAsync(range.Offset, range.Length.Value); }

Remarks

If-Range accepts one matching strong entity tag or an exact last-modified date at whole-second precision. The byte range unit is case insensitive. Multiple ranges are unsupported.

Exceptions

ArgumentOutOfRangeException

length is negative.
