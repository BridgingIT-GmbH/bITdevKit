Remarks

Consumers may treat this contract as optional. When it is not registered, features that support database-readiness coordination should continue without waiting.

WaitForReadyAsync(string, TimeSpan?, TimeSpan?, CancellationToken)

Waits asynchronously for the named database readiness condition.

Task WaitForReadyAsync(string name = null, TimeSpan? pollInterval = null, TimeSpan? timeout = null, CancellationToken cancellationToken = default)

Parameters

name string

The database name, or null to wait for every tracked database.

pollInterval TimeSpan?

The polling interval, defaulting to 200 milliseconds.

timeout TimeSpan?

The maximum wait, defaulting to 30 seconds.

cancellationToken CancellationToken

The cancellation token.

Returns

Task

Examples

await service.WaitForReadyAsync(
    "AppDbContext",
    timeout: TimeSpan.FromMinutes(2),
    cancellationToken: cancellationToken);

Exceptions

InvalidOperationException

Thrown when a requested database is faulted.

TimeoutException

Thrown when readiness is not reached before the timeout.
