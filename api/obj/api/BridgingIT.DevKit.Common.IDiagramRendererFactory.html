TryGetRenderer(DiagramKind, DiagramRenderFormat, out IDiagramRenderer)

Tries to get the renderer registered for the supplied diagram kind and format.

bool TryGetRenderer(DiagramKind kind, DiagramRenderFormat format, out IDiagramRenderer renderer)

Parameters

kind DiagramKind

The diagram kind to resolve.

format DiagramRenderFormat

The render format to resolve.

renderer IDiagramRenderer

The resolved renderer when available.

Returns

bool

true when a renderer is registered; otherwise false.

Examples

var services = new ServiceCollection();
services.AddDiagramRendering();
var provider = services.BuildServiceProvider();
var factory = provider.GetRequiredService<IDiagramRendererFactory>();
if (factory.TryGetRenderer(DiagramKind.Class, DiagramRenderFormat.Mermaid, out var renderer))
{
    var text = renderer.Render(new ClassDiagramBuilder().AddClass("Order").Build()).GetText();
}
