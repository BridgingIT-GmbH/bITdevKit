Examples

using var hash = IncrementalHash.CreateHash(HashAlgorithmName.SHA256);
using (var output = new IncrementalHashWriteStream(hash))
{
    output.Write("inspection report"u8);
}

var fingerprint = Convert.ToHexStringLower(hash.GetHashAndReset());

Remarks

The caller owns and finalizes the hash. Flushing or disposing the stream leaves the hash and its accumulated bytes available. Writes complete inline and concurrent writes are unsupported.
