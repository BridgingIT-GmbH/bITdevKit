Examples

using var output = new LimitedWriteStream(destination, ByteSize.Megabytes(2));
            await producer(output, cancellationToken);
            if (!output.CompletedSuccessfully) { throw new InvalidDataException("The producer failed a write."); }

Remarks

A failed or excessive write permanently rejects the attempt, even when the producer catches its exception. Inspect CompletedSuccessfully before disposing the wrapper. Concurrent writes are unsupported.
