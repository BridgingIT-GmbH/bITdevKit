Remarks

This class provides a fluent API for registering handlers, behaviors, and providers for the Notifier system. It scans assemblies for handlers and validators, caches handler types in a shared IHandlerCache, and registers services with the DI container. Uses HandlerCacheFactory to ensure a single shared cache.

AddGenericHandler(Type, Type, Type[])

Registers generic notification handlers for a specified generic notification type using provided type arguments.

Parameters

genericHandlerType Type

The open generic handler type (e.g., typeof(GenericNotificationHandler<>)).

genericNotificationType Type

The open generic notification type (e.g., typeof(GenericNotification<>)).

typeArguments Type[]

The list of type arguments to create closed generic handlers (e.g., new[] { typeof(UserData) }).

Returns

NotifierBuilder

The NotifierBuilder instance for fluent chaining.

Examples

services.AddNotifier()
    .AddGenericHandler(typeof(GenericNotificationHandler<>), typeof(GenericNotification<>), new[] { typeof(UserData) });

Remarks

Registers closed generic handlers in the DI container and the shared IHandlerCache. Also registers nested validators for the closed notification types if they implement FluentValidation.IValidator<>.

Exceptions

ArgumentException

Thrown when genericHandlerType or genericNotificationType is not an open generic type definition, or if the number of type arguments does not match the generic parameters.

ArgumentNullException

Thrown when genericHandlerType, genericNotificationType, or typeArguments is null or empty.

AddGenericHandlers(IEnumerable<string>)

Automatically discovers and registers generic notification handlers by scanning assemblies for open generic handlers and their corresponding notification types, based on generic constraints.

public NotifierBuilder AddGenericHandlers(IEnumerable<string> blacklistPatterns = null)

Parameters

blacklistPatterns IEnumerable<string>

Optional regex patterns to exclude assemblies (e.g., "^System\..*"). Defaults to ApplicationDependencies.

Returns

NotifierBuilder

The NotifierBuilder instance for fluent chaining.

Examples

services.AddNotifier()
    .AddGenericHandlers(new[] { "^System\\..*" });

Remarks

Discovers types implementing INotificationHandler<TNotification> where TNotification is a generic type definition. Registers closed handlers for concrete types satisfying the generic constraints, along with nested validators.

Exceptions

InvalidOperationException

Thrown when a generic handler has an invalid number of generic parameters or no valid type arguments are found.

Returns

Examples

    .AddHandlers(new[] { "^System\\..*" });

Remarks

Discovers types implementing INotificationHandler<TNotification> where TNotification implements INotification directly or indirectly, including domain-event notification types. Also registers nested validators if they implement FluentValidation.IValidator<> for the notification type.
