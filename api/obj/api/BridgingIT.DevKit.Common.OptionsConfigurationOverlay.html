Applies present configuration properties to a snapshot and replaces supplied collections in full.

public static class OptionsConfigurationOverlay
Inheritance
object
OptionsConfigurationOverlay

Examples

var effective = OptionsConfigurationOverlay.Apply(options, section, provenance);

Remarks

This processes an existing configuration tree once. It does not load files, subscribe to reload, or select feature precedence. Use serializable option data with writable public properties.

Remarks

Absent properties keep their prior values. Nested option objects merge recursively. Arrays, standard list/set shapes, and dictionaries bind as complete replacements. A present collection with no bound value becomes empty. Unknown or non-writable option properties are rejected.
