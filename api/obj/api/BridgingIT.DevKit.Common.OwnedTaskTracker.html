Examples

await using var tasks = new OwnedTaskTracker(TimeSpan.FromSeconds(5));
            tasks.Track(admittedWork, "upload");

Remarks

This grants no capacity and does not start tasks. The caller must independently bound admitted work. Stopping requests cancellation; it never treats an expired wait as completion of the actual work.

An optional host or parent signal which requests cancellation without releasing ownership.
