Examples

var matcher = new PathGlobMatcher(["/reports/**", "/jobs/archive-*"]);
var matches = matcher.IsMatch("/reports/monthly/sales");

Remarks

Use * within a segment and ** as a complete segment to match zero or more segments. Trailing slashes are ignored. Literal comparison uses invariant casing on individual UTF-16 code units. Instances can be shared across callers.
