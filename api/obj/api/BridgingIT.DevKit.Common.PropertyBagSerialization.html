Class PropertyBagSerialization

Namespace
BridgingIT.DevKit.Common

Copies and persists scalar PropertyBag instances using the format defined by PropertyBagScalarCodec for each stored value.

public static class PropertyBagSerialization
Inheritance
object
PropertyBagSerialization

Examples

var inspection = new PropertyBag { ["SampleCount"] = (ushort)42 };
var json = PropertyBagSerialization.Serialize(inspection);
var restored = PropertyBagSerialization.Deserialize(json);
var sampleCount = (ushort)restored.Get("sampleCount");

Deserialize(string)

Reads the persisted dictionary into a case-insensitive bag, restoring encoded scalar types and retaining unprefixed legacy values as strings.

public static PropertyBag Deserialize(string json)

Parameters

json string

The persisted JSON dictionary, or null or empty text.

Returns

PropertyBag

A new bag, empty when json is null, empty, or an empty JSON object.

Examples

Exceptions

JsonException

The input is invalid JSON or cannot be read as a dictionary of strings.

ArgumentNullException

The input is the JSON literal null.

ArgumentException

The dictionary contains keys that differ only by case.

FormatException

An encoded scalar is invalid.
