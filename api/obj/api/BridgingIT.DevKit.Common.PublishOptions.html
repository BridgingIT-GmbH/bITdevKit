Examples

var options = new PublishOptions
{
    ExecutionMode = ExecutionMode.Concurrent,
    Context = new RequestContext { Properties = { ["UserId"] = "user123", ["Locale"] = "en-US" } },
    Progress = new Progress<ProgressReport>(report => Console.WriteLine($"Progress: {report.Messages[0]} ({report.PercentageComplete}%)"))
};
await notifier.PublishAsync(new EmailSentNotification(), options);

Remarks

This class provides configuration options for notification processing, including execution mode, exception handling, a RequestContext for contextual data (e.g., UserId, Locale), and a Progress reporter for tracking progress. It is used by the Notifier and handlers to access additional context and report progress during notification handling.
