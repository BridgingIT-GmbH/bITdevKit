    Console.WriteLine($"Request: {mapping.Key}, Handlers: [{string.Join(", ", mapping.Value)}]");
}
Console.WriteLine($"Behaviors: [{string.Join(", ", information.BehaviorTypes)}]");

Remarks

This class provides insights into the registered components of the Requester or Notifier system, including a mapping of request/notification types to their handler types and a list of registered behavior types. It is returned by GetRegistrationInformation() and GetRegistrationInformation().
