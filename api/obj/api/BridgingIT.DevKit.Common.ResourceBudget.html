Remarks

Pair this with a successful TryCharge(long) on the same budget. Prefer TryReserve(long, out ResourceReservation) for disposable ownership.

TryCharge(long)

Attempts an atomic raw charge across all applicable parent and child ceilings, rolling back a parent when this child rejects it.

public bool TryCharge(long amount)

Parameters

amount long

Returns

bool

Examples

if (budget.TryCharge(1024)) { try { AllocateBuffer(); } finally { budget.Return(1024); } }

Remarks

The caller owns a successful charge and must return it to this same budget. Prefer TryReserve(long, out ResourceReservation) for disposable ownership.
