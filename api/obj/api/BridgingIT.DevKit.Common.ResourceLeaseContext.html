Retains a caller-owned resource while asynchronous work outlives its bounded caller wait.

public static class ResourceLeaseContext

ResourceLeaseContext

Examples

using var lease = ResourceLeaseContext.Begin(decodedGraphCharge); await operation();

Remarks

This context grants no admission. It contains only disposable resource accounts; it never carries payloads, identities or HTTP objects. Dispose scopes in reverse creation order in the same asynchronous flow. Captures may extend a live resource after its original scope closes, provided another capture still owns it. A resource whose last reference was released cannot be resurrected.

Remarks

Nested scopes retain their parent account transitively. Do not also dispose the supplied account independently.
