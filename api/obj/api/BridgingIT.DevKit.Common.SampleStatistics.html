Methods

NearestRank<T>(IReadOnlyList<T>, double)

Selects a nearest-rank quantile from nonempty, ascending observations.

public static T NearestRank<T>(IReadOnlyList<T> sortedValues, double quantile)

Parameters

sortedValues IReadOnlyList<T>

Observations already ordered ascending and stable for this call.

quantile double

The finite fraction from zero through one; zero selects the first observation.

Returns

T

The actual observation at rank ceil(count multiplied by quantile), with a minimum rank of one.

Type Parameters

T

The original observation type, returned without numeric conversion.

Examples

var p50 = SampleStatistics.NearestRank(new[] { 10, 20 }, 0.5); // 10
var p95 = SampleStatistics.NearestRank(orderedDurations, 0.95);

Remarks

This method does not sort, copy or validate the ordering. Nearest-rank p50 can differ from a midpoint median.

Exceptions

ArgumentNullException

The observations are null.

ArgumentException

The observations are empty.

ArgumentOutOfRangeException

The quantile is nonfinite or outside zero through one.
