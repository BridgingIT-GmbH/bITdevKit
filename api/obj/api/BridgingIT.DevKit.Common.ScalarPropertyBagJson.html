Methods

Parse(string, bool)

Reads JSON strings, Boolean values, nulls, and numbers into a new property bag.

public static Result<PropertyBag> Parse(string json, bool preserveMissing = false)

Parameters

json string

A JSON object, a JSON null, or omitted text.

preserveMissing bool

Return a null bag for omitted, blank, or JSON null input when true. Otherwise return an empty bag. An explicit empty object always returns an empty bag.

Returns

Result<PropertyBag>

The parsed bag or the requested missing value on success. A ValidationError reports JSON syntax errors, non-object roots other than null, blank property names, nested values, or numbers outside the supported range.

Remarks

Numbers use long when possible, then decimal if its conversion to double agrees with the parsed double, and otherwise a finite double. Nonzero numbers that round to zero as a double are rejected. Case-insensitive duplicate keys keep the first spelling and last value.

Exceptions

InvalidOperationException

Decoding a property name or string value encounters an unpaired surrogate escape.
