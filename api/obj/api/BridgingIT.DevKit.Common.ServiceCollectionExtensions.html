AddNotifier(IServiceCollection)

Adds the Notifier service to the specified Microsoft.Extensions.DependencyInjection.IServiceCollection and returns a NotifierBuilder for configuration.

public static NotifierBuilder AddNotifier(this IServiceCollection services)

Parameters

services IServiceCollection

Returns

NotifierBuilder

A NotifierBuilder for fluent configuration.

Examples

// Basic usage with default configuration
var services = new ServiceCollection();
services.AddLogging(); // Required for INotifier logging
services.AddNotifier()
    .AddHandlers(new[] { "^System\\..*" }); // Exclude System assemblies
var provider = services.BuildServiceProvider();
var notifier = provider.GetRequiredService<INotifier>();
var result = await notifier.PublishAsync(new EmailSentNotification());

// Usage with pipeline behaviors
var services = new ServiceCollection();
services.AddLogging();
services.AddNotifier()
    .AddHandlers(new[] { "^System\\..*" })
    .WithBehavior<ValidationBehavior<,>>() // Add validation behavior
    .WithBehavior<RetryBehavior<,>>();    // Add retry behavior
var provider = services.BuildServiceProvider();
var notifier = provider.GetRequiredService<INotifier>();
var result = await notifier.PublishAsync(new EmailSentNotification());

Remarks

This method registers the necessary services for the Notifier system, including the INotifier implementation and its dependencies. It returns a NotifierBuilder that can be used to configure handlers and behaviors using a fluent API. The Notifier system enables dispatching notifications to their corresponding handlers through a pipeline of behaviors, supporting features like validation, retry, and timeout.

To use the Notifier system, you must: 1. Call AddNotifier(IServiceCollection) to register the core services. 2. Use AddHandlers(IEnumerable<string>) to scan for and register notification handlers. 3. Optionally, use WithBehavior(Type) to add pipeline behaviors. 4. Build the service provider to resolve the INotifier service for dispatching notifications.

The INotifier service is registered with a scoped lifetime, meaning a new instance is created for each scope (e.g., per HTTP request in ASP.NET Core). Ensure that any dependencies (e.g., logging) are also registered in the service collection before calling this method.

Exceptions

ArgumentNullException

Thrown when services is null.
