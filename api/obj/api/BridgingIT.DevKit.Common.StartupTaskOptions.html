Properties

Enabled

Gets or sets a value indicating whether the startup task is enabled.

public bool Enabled { get; set; }

Property Value

bool

A boolean value where true indicates the startup task is enabled, and false indicates it is disabled. The default value is true.

Remarks

This property is used to control the execution of startup tasks. By setting it to false, the startup task can be skipped.

HaltOnFailure

Gets or sets a value indicating whether the application process should be terminated immediately when this startup task fails.

public bool HaltOnFailure { get; set; }

Property Value

bool

Remarks

When enabled, a failure triggers System.Environment.FailFast(string, System.Exception) after logging.

Order

Gets or sets the execution order of the startup task.

public int Order { get; set; }

Property Value

int

Remarks

A lower value indicates a higher priority, meaning the task will be executed earlier during the startup process. The default value is 0, which means no particular order.

StartupDelay

Gets or sets the delay before the startup task begins execution.

public TimeSpan StartupDelay { get; set; }

Property Value

TimeSpan

Remarks

The delay can be specified as a System.TimeSpan value. This allows for configurable postponement of the task, useful for tasks that should not start immediately when the application launches.
