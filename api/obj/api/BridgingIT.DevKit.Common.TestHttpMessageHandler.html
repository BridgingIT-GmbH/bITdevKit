A test utility class for unit testing HTTP-based services.

TestHttpMessageHandler allows you to inject custom HTTP responses when using System.Net.Http.HttpClient in unit tests. This makes it possible to simulate various HTTP scenarios (success, error, etc) without making actual network calls or using a mocking framework for System.Net.Http.HttpClient.

Usage example: 

var handler = new TestHttpMessageHandler(request => Task.FromResult(new HttpResponseMessage(HttpStatusCode.OK)));
var httpClient = new HttpClient(handler);
