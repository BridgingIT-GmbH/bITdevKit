A custom System.Text.Json.Serialization.Metadata.DefaultJsonTypeInfoResolver implementation that provides universal support for deserializing types with public or private constructors and properties with public or private setters, including inherited properties. This resolver dynamically configures object creation and property setters using reflection to handle various accessibility scenarios, making it suitable for immutable or complex object graphs without requiring attributes like [JsonInclude] or [JsonConstructor].

Examples

var options = new JsonSerializerOptions
{
    TypeInfoResolver = new UniversalContractResolver(),
    PropertyNameCaseInsensitive = true
};
var json = @"{""id"": 1, ""name"": ""Test""}";
var result = JsonSerializer.Deserialize<TestClass>(json, options);

Where TestClass might be:

public class TestClass
{
    public int Id { get; private set; }
    public string Name { get; private set; }
    private TestClass() { }
}

Remarks

This resolver is designed to work with System.Text.Json serialization and deserialization processes. It ensures that types can be instantiated using their most accessible parameterless constructor (public preferred, falling back to non-public) and that all writable properties, including those with private setters, are populated from JSON data.

Key features include:

  • Support for public and private constructors, prioritizing parameterless constructors.
  • Configuration of property setters for both public and private setters using reflection.
  • Inclusion of inherited properties from base classes using System.Reflection.BindingFlags.FlattenHierarchy.
  • Case-insensitive property name matching to align JSON keys with .NET property names.
  • Optional support for System.Text.Json.Serialization.JsonPropertyNameAttribute to map custom JSON property names.

Limitations:

  • Relies on reflection, which may impact performance and is not AOT-friendly without source generation.
  • Currently supports only parameterless constructors; parameterized constructors require additional customization.
  • Does not validate required properties; manual validation may be needed for critical data.

Remarks

This method checks if the type is an object and configures its creation and property settings. It prioritizes a public parameterless constructor, falls back to a non-public one, and sets up property setters for all writable properties, including those with private access.
