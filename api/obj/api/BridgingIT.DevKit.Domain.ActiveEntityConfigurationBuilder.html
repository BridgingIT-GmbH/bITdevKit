For<TEntity, TId>(Action<ActiveEntityConfigurator<TEntity, TId>>)

Configures Active Entity for a specific entity type with its identifier type.

public ActiveEntityConfigurator<TEntity, TId> For<TEntity, TId>(Action<ActiveEntityConfigurator<TEntity, TId>> configure = null) where TEntity : ActiveEntity<TEntity, TId>, IEntity

Parameters

configure Action<ActiveEntityConfigurator<TEntity, TId>>

Optional configuration action for the entity.

Returns

ActiveEntityConfigurator<TEntity, TId>

The entity configurator for fluent chaining.

Type Parameters

TEntity

The entity type, must inherit from ActiveEntity<TEntity, TId>.

TId

The type of the entity's identifier.

Examples

builder.For<Customer, CustomerId>(cfg => cfg
    .UseEntityFrameworkProvider<AppDbContext>()
    .AddLoggingBehavior());

Remarks

The entity type is recorded in the ActiveEntityRegistry so tooling such as the Entities dashboard can discover it.

Exceptions

ArgumentNullException

Thrown when services is null.
