An aggregate root is an entity which works as an entry point to our aggregate. All business operations + domain events should go through the root. This way, the aggregate root can take care of keeping the aggregate in a consistent state.

DomainEvents

Remarks

DomainEvents is used to register and manage events that occur within the lifecycle of the aggregate root. It's accessible within the aggregate root to enable raising events in response to state changes. Events registered in DomainEvents can trigger subsequent actions or updates in other parts of the system.
