Namespace
BridgingIT.DevKit.Domain.Repositories

BridgingIT.DevKit.Domain.dll

Thread-safe implementation of IDatabaseReadyService for tracking readiness and fault state of multiple named databases. Allows modules to mark databases as ready or faulted, and consumers to query or await readiness.

WaitForReadyAsync(string, TimeSpan?, TimeSpan?, CancellationToken)

Waits asynchronously for the named database readiness condition.

public Task WaitForReadyAsync(string name = null, TimeSpan? pollInterval = null, TimeSpan? timeout = null, CancellationToken cancellationToken = default)

Parameters

name string

The database name, or null to wait for every tracked database.

pollInterval TimeSpan?

The polling interval, defaulting to 200 milliseconds.

timeout TimeSpan?

The maximum wait, defaulting to 30 seconds.

cancellationToken CancellationToken

The cancellation token.

Returns

Task

Examples

await service.WaitForReadyAsync(
    "AppDbContext",
    timeout: TimeSpan.FromMinutes(2),
    cancellationToken: cancellationToken);

Exceptions

InvalidOperationException

Thrown when a requested database is faulted.

TimeoutException

Thrown when readiness is not reached before the timeout.
