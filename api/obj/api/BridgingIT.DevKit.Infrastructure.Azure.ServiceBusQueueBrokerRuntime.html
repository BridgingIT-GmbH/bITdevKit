Tracks lightweight runtime state for the Azure Service Bus queue broker to support operational queries.

public class ServiceBusQueueBrokerRuntime
Inheritance
object
ServiceBusQueueBrokerRuntime

Remarks

This runtime does not retain full message history. It tracks recently enqueued and processed messages in memory for operational visibility while the broker delegates persistence to Azure Service Bus.
