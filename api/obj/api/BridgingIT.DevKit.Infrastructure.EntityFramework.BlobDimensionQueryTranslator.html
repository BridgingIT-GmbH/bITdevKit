public static Task<Result<IQueryable<StorageBlob>>> ApplyAsync<TContext>(TContext context, IQueryable<StorageBlob> owners, string scope, BlobDimensionFilter filter, BlobDimensionCapabilities capabilities, BlobDimensionNameResolver<TContext> resolver, CancellationToken token) where TContext : DbContext

Parameters

context TContext

The context used to resolve names and query the dimension rows.

owners IQueryable<StorageBlob>

The blob rows already restricted to the requested container.

scope string

The container name used to resolve dimension names.

filter BlobDimensionFilter

The filter to apply. A null filter returns the supplied owner query.

capabilities BlobDimensionCapabilities

The dimension operations supported by the current provider.

resolver BlobDimensionNameResolver<TContext>

The resolver for dimension names in the current store.

token CancellationToken

Cancels dimension name resolution.

Returns

Task<Result<IQueryable<StorageBlob>>>

A composable owner query on success or the validation or name resolution errors on failure.

Type Parameters

TContext

The relational context type that maps blobs and their dimension tables.

Examples

var result = await BlobDimensionQueryTranslator.ApplyAsync(
    context, context.StorageBlobs.Where(row => row.Container == "reports"), "reports",
    filter, capabilities, resolver, cancellationToken);

BuildCandidates(DbContext, IQueryable<Guid>, BlobDimensionFilter, IReadOnlyDictionary<string, long>)

Builds a query for matching blob IDs using indexed dimension rows and resolved names.

public static IQueryable<Guid> BuildCandidates(DbContext context, IQueryable<Guid> universe, BlobDimensionFilter filter, IReadOnlyDictionary<string, long> names)

Parameters

context DbContext

The relational context that maps the blob dimension tables.

universe IQueryable<Guid>

The blob IDs in scope, used for filter branches without an indexed match to start from.

filter BlobDimensionFilter

A filter already validated against the provider's dimension capabilities.

names IReadOnlyDictionary<string, long>

The dictionary IDs for the canonical dimension names found in scope.

Returns

IQueryable<Guid>

A deferred query for the candidate IDs. Join it to the scoped owner query before returning blobs.

Examples

var ownerIds = context.StorageBlobs.Where(row => row.Container == "reports").Select(row => row.Id);
var candidates = BlobDimensionQueryTranslator.BuildCandidates(context, ownerIds, filter, resolvedNames);
