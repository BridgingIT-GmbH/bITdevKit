WithEntityFrameworkProvider<TContext>(ApplicationCachingBuilderContext)

Registers the complete EntityFramework provider using the host's registered context factory.

public static ApplicationCachingBuilderContext WithEntityFrameworkProvider<TContext>(this ApplicationCachingBuilderContext builder) where TContext : DbContext, IApplicationCachingContext

Parameters

builder ApplicationCachingBuilderContext

The advanced-cache registration builder.

Returns

ApplicationCachingBuilderContext

The same builder for additional cache registration.

Type Parameters

TContext

The host context implementing the advanced-cache persistence capability.

Examples

services.AddDbContextFactory<CatalogDbContext>(options => options.UseSqlServer(connectionString));
services.AddApplicationCaching().WithEntityFrameworkProvider<CatalogDbContext>();

Remarks

Register IDbContextFactory<TContext> with a lifetime compatible with the cache provider. Factory resolution and context creation remain lazy until native access. Every bounded operation owns and disposes its fresh context; request-scoped contexts are never borrowed. Consumers deploy their own migrations before database readiness.

Exceptions

ArgumentNullException

The builder is null.

WithEntityFrameworkProvider<TContext>(ApplicationCachingBuilderContext, string, Action<EntityFrameworkCacheProviderOptionsBuilder>)

Declares one named EntityFramework provider using its module's registered context factory.

public static ApplicationCachingBuilderContext WithEntityFrameworkProvider<TContext>(this ApplicationCachingBuilderContext builder, string name, Action<EntityFrameworkCacheProviderOptionsBuilder> configure = null) where TContext : DbContext, IApplicationCachingContext

Parameters

builder ApplicationCachingBuilderContext

The shared advanced-cache registration builder.

name string

The unique provider alias selected by collections.

configure Action<EntityFrameworkCacheProviderOptionsBuilder>

Optional native provider settings, below configuration overrides.

Returns

ApplicationCachingBuilderContext

The same builder for additional module registration.

Type Parameters

TContext

The module context implementing the advanced-cache persistence capability.

Examples

services.AddApplicationCaching().WithEntityFrameworkProvider<CatalogDbContext>("catalog", provider => provider.SqlServer());

Remarks

Each name selects only its code-registered context type. The engine is inferred from DevKit context registrations when the catalog is finalized; absent metadata defaults to SQLite. An explicit typed engine overrides inference, and configuration overrides fluent settings. Register a singleton-compatible IDbContextFactory<TContext>; each native operation creates and disposes its own context. Select a database readiness alias explicitly when required by the host.

Exceptions

ArgumentNullException

The builder is null.

ArgumentException

The provider alias is invalid or already declared.

InvalidOperationException

The shared startup catalog is finalized.
