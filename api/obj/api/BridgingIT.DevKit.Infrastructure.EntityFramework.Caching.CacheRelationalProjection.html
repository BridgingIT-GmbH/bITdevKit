Examples

var row = await CacheRelationalProjection.SingleAsync(context, context.Set<CacheStoreEntity>().Where(entity => entity.Id == "root"), true, token);

Remarks

Selectors use trusted entity annotations and fixed JSON-format ceilings. Oversized binary fields are not retrieved, and clipped scalar fields retain one excess character so corruption cannot become a truncated identity.
