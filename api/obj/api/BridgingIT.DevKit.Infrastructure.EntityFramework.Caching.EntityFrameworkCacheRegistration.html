Owns code-registered module context dispatch behind one shared EntityFramework cache kind.

public sealed class EntityFrameworkCacheRegistration
Inheritance
object
EntityFrameworkCacheRegistration

Examples

services.AddApplicationCaching().WithEntityFrameworkProvider<CatalogDbContext>("catalog");

Remarks

Named registrations override the optional default factory. The owner builder's finalization closes every registration path; native provider creation only reads the private factory catalog.
