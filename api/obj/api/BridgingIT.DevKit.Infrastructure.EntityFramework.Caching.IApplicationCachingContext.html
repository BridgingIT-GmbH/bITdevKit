Interface IApplicationCachingContext

BridgingIT.DevKit.Infrastructure.EntityFramework.Caching

BridgingIT.DevKit.Infrastructure.EntityFramework.dll

Defines the opt-in Entity Framework persistence capability for advanced application caching.

public interface IApplicationCachingContext

Examples

services.AddDbContextFactory<CatalogDbContext>(options => options.UseSqlServer(connectionString));
services.AddApplicationCaching().WithEntityFrameworkProvider<CatalogDbContext>();

Remarks

Implement this interface on a ModuleDbContextBase to apply the annotated cache model automatically. Other DbContext types call CacheModelConfiguration.Configure from OnModelCreating. Deploy host-owned migrations for their own context before readiness. The provider package contains no migration or deployment SQL. Adding the interface never creates or migrates a database at request time. This capability is independent of Common.Caching and Key/Value Storage.
