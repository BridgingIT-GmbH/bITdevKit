Remarks

Discovery looks at every configuration key whose path contains ConnectionString. A key is claimed when its value parses as a connection string of the provider and names a database. Keys that point at the same server and database form one resource, so they all get the same instance database.

Only the database name changes. Credentials and every other option are kept and never logged.

Remarks

Detection is file-based and never starts a Git process. Outside a linked worktree, with DevAppInstance:Mode=Disabled, or when no application of the worktree manages connectionStringKey, the connection string is returned unchanged.

Thrown when the linked worktree has not started an application yet.
