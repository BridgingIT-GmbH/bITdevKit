Resolves Entity Framework Microsoft.EntityFrameworkCore.DbContext instances at runtime for transactional behaviors and other cross-cutting concerns.

public interface IDbContextResolver

Remarks

Supports two resolution forms: - By context name (string): logical name that may omit the "DbContext" suffix (e.g., "Core" resolves to "CoreDbContext"). The resolver locates the corresponding DbContext type once and caches it, then retrieves the instance from DI. - By type (Type): the exact Microsoft.EntityFrameworkCore.DbContext derived type. The resolver retrieves the instance from DI without any reflection or lookup.

Requirements: - The DbContext type must be registered in DI using AddDbContext<TContext>(). - For name-based resolution, the DbContext type must be loadable in the current AppDomain.
