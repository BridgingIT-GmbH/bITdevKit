Writes prepared entity bulk insert batches through one Entity Framework database provider.

public interface IEntityBulkInsertProvider

Examples

var inserted = await provider.InsertAsync(dbContext, batch, cancellationToken);

Remarks

Implementations are stateless provider strategies registered by their provider package. The shared bulk inserter selects the strategy by Microsoft.EntityFrameworkCore.DbContext.Database provider name, opens the connection, and supplies an active EF transaction before execution. Implementations must not create, commit, or roll back an internal transaction.

A task whose result is the number of inserted rows.

Examples

var inserted = await provider.InsertAsync(dbContext, batch, cancellationToken);

Remarks

Relational implementations require an open connection and active transaction supplied through context. Implementations should throw provider-native failures. The shared orchestrator converts those failures to Result<long>, rolls back only its own transaction, and preserves System.OperationCanceledException.
