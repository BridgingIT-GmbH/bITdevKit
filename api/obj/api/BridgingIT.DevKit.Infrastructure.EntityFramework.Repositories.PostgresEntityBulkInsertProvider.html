Remarks

This provider is registered automatically by AddPostgresDbContext so the shared bulk-insert dispatcher selects it for Npgsql contexts. Native PostgreSQL bulk insert support has not been implemented yet.

A task whose result is the number of inserted rows.

Type Parameters

Examples

var inserted = await provider.InsertAsync(dbContext, batch, cancellationToken);

Remarks

Relational implementations require an open connection and active transaction supplied through context. Implementations should throw provider-native failures. The shared orchestrator converts those failures to Result<long>, rolls back only its own transaction, and preserves System.OperationCanceledException.

Exceptions

NotImplementedException

Always thrown until PostgreSQL-native bulk insert support is implemented.
