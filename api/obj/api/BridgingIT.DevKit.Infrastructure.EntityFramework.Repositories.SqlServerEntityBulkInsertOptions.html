    });

Remarks

CommandTimeout configures Microsoft.Data.SqlClient.SqlBulkCopy.BulkCopyTimeout. Set KeepGeneratedIdentityValues to preserve store-generated identity values; do not add Microsoft.Data.SqlClient.SqlBulkCopyOptions.KeepIdentity or Microsoft.Data.SqlClient.SqlBulkCopyOptions.UseInternalTransaction to SqlBulkCopyOptions, because the provider derives those flags from the neutral option and the active EF transaction.
