Remarks

This stateless provider is registered automatically by AddSqlServerDbContext. Entity metadata, generated values, value conversion, and result conversion are handled by the shared bulk-insert dispatcher.

Examples

Remarks

Relational implementations require an open connection and active transaction supplied through context. Implementations should throw provider-native failures. The shared orchestrator converts those failures to Result<long>, rolls back only its own transaction, and preserves System.OperationCanceledException.
