Remarks

Only Microsoft.Data.Sqlite.SqliteConnectionStringBuilder.DataSource changes. The instance file stays in the directory of the baseline file, and a relative path stays relative. In-memory databases (:memory: or Mode=Memory) are not claimed. Inventories record the full path, resolved against the current directory.
