DownloadManyAsync(IReadOnlyCollection<BlobKey>, CancellationToken)

Downloads many blobs by exact key with as few round trips as the provider can manage.

public Task<IReadOnlyDictionary<BlobKey, Result<StoredBlobDownload>>> DownloadManyAsync(IReadOnlyCollection<BlobKey> keys, CancellationToken cancellationToken = default)

Parameters

keys IReadOnlyCollection<BlobKey>

The distinct exact blob keys, at most MaxDownloadBatchSize.

cancellationToken CancellationToken

The token used to cancel the operation.

Returns

Task<IReadOnlyDictionary<BlobKey, Result<StoredBlobDownload>>>

A dictionary with one result per key the provider could satisfy. Keys that are missing from the dictionary (for example blobs too large to buffer, or a failed batch) are read with DownloadAsync(BlobKey, CancellationToken) instead, so a batch never changes the outcome of a read. The caller owns and disposes every returned StoredBlobDownload.

Examples

var results = await provider.DownloadManyAsync(keys, cancellationToken);

ListPageAsync(BlobFilterQuery, int, CancellationToken)

Lists one page of metadata matching key and Dimension criteria.

public Task<Result<StoredBlobPage>> ListPageAsync(BlobFilterQuery query, int pageSize, CancellationToken cancellationToken)

Parameters

query BlobFilterQuery

The validated scope, predicates, and seek order.

pageSize int

The maximum number of metadata items to return.

cancellationToken CancellationToken

The token used to cancel provider I/O.

Returns

Task<Result<StoredBlobPage>>

A page with a JSON string array in ContinuationToken when more items exist. The final page has a null token.

Examples

var page = await provider.ListPageAsync(query, pageSize, cancellationToken);

Remarks

The continuation array contains the last returned name and its SHA-256 lookup hash in that order. The client validates and wraps the array before returning a public token.
