Move(string, string, bool, bool)

Publishes a same-directory namespace entry using native atomic replacement or exclusive installation.

public static void Move(string source, string destination, bool overwrite, bool durable)

Parameters

source string

An existing staged file, or a directory for Windows exclusive initialization.

destination string

The destination in the exact same directory.

overwrite bool

Whether to atomically replace the destination or fail if it exists.

durable bool

Whether to synchronize the containing Linux directory or request Windows write-through persistence.

Examples

FileSystemDurability.Move(staging, target, overwrite: true, durable: true);

Remarks

Flush source file data first. Linux exclusive installation uses link/unlink; failed source cleanup can leave an extra name. Any publication failure may require outcome reconciliation.

Exceptions

InvalidOperationException

Source and destination have different directory strings.

FileSystemConfigurationException

A required native operation is unsupported.
