Probe(string)

Observes the filesystem containing a fully qualified path, which need not exist yet.

public static FileSystemKind Probe(string root)

Parameters

root string

The normalized absolute path to inspect.

Returns

FileSystemKind

The supported observed kind, or Unsupported when the native protocol cannot be identified or the host is neither Windows nor Linux.

Examples

var kind = FileSystemKindProbe.Probe(Path.Combine(Path.GetTempPath(), "report-store"));

Remarks

Linux selects the longest matching mount in /proc/self/mountinfo. Windows recognizes local drives and inspects the nearest existing directory on network drives for SMB 3 or later. Native filesystem access can block or throw I/O and access exceptions.
