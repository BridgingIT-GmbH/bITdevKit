Exposes process-wide instrumentation for filesystem storage operations.

public static class FileSystemMetrics
Inheritance
object
FileSystemMetrics

Examples

var before = FileSystemMetrics.Snapshot();

Remarks

Counters describe application observations, not proven syscalls or remote RPCs. Fields are writable for isolated diagnostic resets; use Interlocked for concurrent access. Resetting during a measurement invalidates its deltas. Counters never determine storage ownership or correctness.

Methods

Snapshot()

Copies named process counters using atomic reads of each value.

public static Dictionary<string, long> Snapshot()

Returns

Dictionary<string, long>

A new dictionary of instrumentation values suitable for before/after measurement deltas.

Examples

var after = FileSystemMetrics.Snapshot(); var bytes = after["stagedBytes"];

Remarks

The snapshot is independent and not an atomic transaction across counters. Stopwatch tick durations use the runtime's Stopwatch.Frequency. The last native diagnostic error is available separately through IndeterminateNativeCode.
