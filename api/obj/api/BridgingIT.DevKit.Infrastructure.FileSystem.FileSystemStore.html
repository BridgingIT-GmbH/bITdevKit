Examples

var store = new FileSystemStore(options); var path = store.Resolve(["blobs", "reports", "daily"], false);

Remarks

This low-level API is for trusted tooling operating on a provider-owned root. Paths and records must come from this store. Acquire key authority before reading metadata used by a mutation or opening its selected payload. Keep it through publication. All cooperating participants must use the same protocol. Shared deployment and power-loss qualification remain separate.
