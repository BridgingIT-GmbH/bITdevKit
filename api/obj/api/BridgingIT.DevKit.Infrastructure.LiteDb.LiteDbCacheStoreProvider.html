Stores Application Caching metadata, publication authority, quotas, operations and immutable payload chunks in one owned native database.

public sealed class LiteDbCacheStoreProvider : ICacheStoreProvider
Inheritance
object
LiteDbCacheStoreProvider

Examples

services.AddApplicationCaching().WithLiteDbProvider("catalog");

Remarks

Coordination is confined to this process. Native calls execute synchronously on the named database's worker.
