Represents a durable broker message row stored in native LiteDB persistence.

public class LiteDbQueueMessage : ILiteDbIndexedRecord
Inheritance
object
LiteDbQueueMessage

Remarks

The entity keeps the serialized payload and a JSON-backed collection of handler states so the broker can coordinate multi-node leasing and handler-specific retry state without additional tables.
