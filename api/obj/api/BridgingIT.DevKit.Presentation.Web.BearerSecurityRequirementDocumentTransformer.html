Remarks

This transformer adds HTTP Bearer token authentication to the OpenAPI specification, enabling API clients and documentation tools (such as Scalar) to support authentication through JWT bearer tokens.

Key responsibilities:

  • Adds an HTTP Bearer security scheme to the OpenAPI components
  • Applies the security requirement to all operations as the default authentication method
  • Enables API documentation tools to provide authentication UI and token management

Remarks

This method:

  1. Ensures the document has a components section
  2. Adds an HTTP Bearer security scheme using the default JWT bearer authentication scheme name
  3. Applies the security requirement to all operations, making Bearer authentication the default

The Bearer token is configured as an HTTP scheme, which is the OpenAPI representation for a JWT supplied in the Authorization header.
