Owns an explicit connection between one AppState instance and native Blazor persistence.

AppStateLifecycle

Examples

using var lifecycle = AppStateLifecycle.Attach(state, persistentState,
    CatalogJson.Default.CatalogViewModel, RenderMode.InteractiveServer);
if (!lifecycle.Restored)
{
    var next = state.TakeSnapshot();
    next.Page = 1;
    await state.RestoreSnapshot(next);
}

Remarks

Attach once per logical instance after establishing host context. Dispose before releasing a component-owned state. Only approved model values cross the render-mode boundary. This handle never owns the state or its injected services.

Remarks

Native Blazor's imperative string serialization requires JSON reflection to be enabled in the host. Feature model serialization uses the supplied metadata. Missing, corrupt or superseded snapshots retain current values.
