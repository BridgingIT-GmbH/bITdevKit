AddDevAppInstance(DevKitWebApplicationBuilder, Action<DevAppInstanceBuilder>)

Configures linked-worktree development isolation and activates it now. Isolation is on by default for every DevKit web host, so call this only to change the defaults or to turn it off with Enabled(bool). Call after configuration composition and before logging, modules, DbContext registrations or the build, because the first of those activates the defaults. In the Development environment the database adapters of referenced EF Core provider packages are found automatically. Without WithAppId(string), the application ID derives from the host application name. Without WithHttpOffset(int, int?), the registry assigns the port offsets.
