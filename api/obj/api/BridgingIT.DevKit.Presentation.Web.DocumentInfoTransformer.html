Remarks

This transformer configures the OpenAPI document's info section with customized title, version, description, and other metadata. It can be configured through dependency injection or use sensible defaults.

Key responsibilities:

  • Sets the API title
  • Sets the API version
  • Adds or updates the API description
  • Optionally adds contact and license information
  • Can extract version from assembly or configuration
