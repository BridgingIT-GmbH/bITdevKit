AllowNonPublicSetters()

Allows the dashboard to use non-public setters and a non-public parameterless constructor for this entity.

public EntitiesDashboardEntityBuilder<TEntity> AllowNonPublicSetters()

Returns

EntitiesDashboardEntityBuilder<TEntity>

The same builder.

Examples

options.Entity<Customer>(e => e.AllowNonPublicSetters());

Remarks

Reflection writes bypass domain invariants in setters and factory methods. Enable this only for entities where that risk is acceptable; repository or ActiveEntity behaviors still run on the save call.
