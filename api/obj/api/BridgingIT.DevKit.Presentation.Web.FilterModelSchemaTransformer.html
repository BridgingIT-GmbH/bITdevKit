Remarks

The .NET 9 OpenAPI generator creates incomplete schemas for types that are only referenced indirectly (e.g., FilterCriteria is only used inside List<FilterCriteria>). This transformer enhances these incomplete schemas with their full definitions during schema generation.

Key responsibilities:

  • Completes schemas for all FilterModel-related types with their full property definitions
  • Defines enum values inline where they are used (not as separate schema references)
  • Handles polymorphic types like SpecificationNode
  • Removes temporary dummy properties used for schema discovery
  • Adds proper descriptions and references to all properties
