Defines a modular Minimal API endpoint set that can be registered with dependency injection and mapped by the endpoint system.

public interface IEndpoints

Remarks

Implementations are discovered or registered as IEndpoints services and are mapped by MapEndpoints. The mapper skips endpoint sets that are disabled or have already been registered, then marks successfully mapped instances as registered.

Example:

public sealed class TodoEndpoints : EndpointsBase
{
    public override void Map(IEndpointRouteBuilder app)
    {
        app.MapGet("/todos", () => Results.Ok());
    }
}

Properties

Enabled

Gets or sets whether this endpoint set should be mapped.

bool Enabled { get; set; }

Property Value

bool

Remarks

MapEndpoints reads this flag before calling Map(IEndpointRouteBuilder). Disabled endpoint sets remain registered in dependency injection but are not mapped into the route table.

IsRegistered

Gets or sets whether this endpoint set has already been mapped.

bool IsRegistered { get; set; }

Property Value

bool

Remarks

The mapping extension sets this property to true after invoking Map(IEndpointRouteBuilder). This prevents the same endpoint instance from being mapped more than once when MapEndpoints is called repeatedly.
