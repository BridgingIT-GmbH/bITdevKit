Remarks

This transformer modifies the OpenAPI schema for ResultProblemDetails, ResultProblemData, ResultProblemError, and ProblemError to enhance their documentation and explicitly allow arbitrary additional properties.

For each matching schema, this transformer:

  • Adds comprehensive descriptions to all objects and their properties
  • Sets the schema type to "object"
  • Sets additionalPropertiesAllowed to true
  • Generates "additionalProperties": {} in the OpenAPI JSON for RFC 7807 compliance

This is essential for RFC 7807 problem details that include extension data and custom error information. Each distinct schema type is logged only once during the build-time document generation process.
