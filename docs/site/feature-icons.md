# Feature Icons

The feature icons share a 32 × 32 grid, rounded 1.6-unit strokes, and two colors from the selected documentation theme. Each card links to its feature guide and standalone SVG. Related subfeatures use a common shape with a distinct detail.

Use the theme picker to compare palettes. The [SVG sprite](assets/features/features.svg) and [catalog metadata](assets/features/catalog.json) are available for reuse. See the [authoring guide](https://github.com/BridgingIT-GmbH/bITdevKit/blob/main/docs/assets/features/README.md) to add an icon.
